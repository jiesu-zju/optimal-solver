# protocol/

Frozen experimental-protocol documents behind the manuscript:

- `PROTOCOL_v1.md` — the seed-budgeting protocol (reward, batch semantics,
  budget accounting, thesis statement).
- `FROZEN_FOR_MANUSCRIPT.md` — the Plan-B freeze statement: RNG set, per-benchmark
  parameters, and the exact tables reproduced from `../traces/`.
- `THESIS_ONEPAGER.md` — the paper's thesis and non-claims.
- `THEORY_RANKING.md` — the ranking-inversion theory (Propositions A–C) that the
  manuscript formalises as Lemma 1 / Corollary 1.
- `PROP_BC_EMPIRICS.md` — the empirical ranking-flip witnesses behind
  Table III/IV of the manuscript.

These documents mirror the manuscript's Method/Experiments sections; the
manuscript itself is the authoritative presentation.
